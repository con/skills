# Troubleshooting

| Symptom                                                                      | Cause and fix                                                                                                                                                                                               |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Captures from several Playwright projects overwrite each other               | Chromatic names an archive by the test's file, describe and title, not its project. Set viewports per test with `forEachViewport`; keep one Chromium project.                                              |
| Two captures overwrite each other within one project                         | Same name: two `takeSnapshot` calls with one name in a test, or two test files whose names sanitize alike (`About.test.ts` and `about.test.ts`). Rename one.                                                 |
| A page's snapshot shows the index page                                       | The URL did not match a built entry and Vite's default `appType: "spa"` fell back to `index.html`. Set `appType: "mpa"` so it 404s, and check the page is in `configs/pages.ts` and the URL form in `several-pages.md`. |
| `Chromatic archives directory cannot be found`                               | A custom `outputDir` in the Playwright config, or the tests did not run. Leave `outputDir` alone or set `CHROMATIC_ARCHIVE_LOCATION` to match.                                                              |
| `build-archive-storybook` ignores `--output-dir`                             | It was run through `npm exec`, which eats the flag. Call `./node_modules/.bin/build-archive-storybook` directly.                                                                                            |
| `Failed to run chromatic --playwright`                                       | No Chromium project; Chromatic archives only from Chromium.                                                                                                                                                 |
| Every story re-snapshotted after a version bump                              | The version stamp is not pinned under `CHROMATIC_STATIC_VERSION` in the Vite config Storybook loads (or in `viteFinal`, when it loads none).                                                                |
| Text pixels moved with no code change                                        | The runner image changed (compare the printed `ImageVersion`), or the branch is behind `main`. Accept, or merge `main` and re-read.                                                                         |
| Workflow fails on a Dependabot or fork branch                                | No secrets there. The `dependabot[bot]` guard skips the former; for forks, see `fork-pull-requests.md`.                                                                                                     |
| `ERR_REQUIRE_ESM` or Node version errors from `@chromatic-com/playwright`    | The package is ESM-only and needs Node 22; raise `node-version` in the workflow.                                                                                                                             |
| Stories show the wrong theme on CI, or only one theme reaches Chromatic      | Nothing pins the theme, or `parameters.chromatic.modes` is missing from `preview.ts`, or the decorator does not read `context.globals.theme`. Add the decorator and the modes block from the template.      |
| A raw-HTML page story shows broken images                                    | Its `/src/assets/...` URLs bypass Vite; add the `staticDirs` mount in `main.ts`. In a nested page (`help/index.html`), relative URLs resolve against Storybook's iframe, not the page's folder: write them root-absolute. |
| A page story renders unstyled                                                | The page links a stylesheet of its own that `preview.ts` does not import; import it at the top of that page's story file.                                                                                   |
| A page works under `npm run dev` but 404s under `vite preview` and in production | The dev server serves any HTML file; the build contains only the entries in `build.rollupOptions.input`. Add the page to `configs/pages.ts`, which the Vite config reads.                                 |
| `playwright install --with-deps` fails locally asking for a password          | `--with-deps` installs system libraries and needs root. Locally run `npx playwright install chromium`; the flag is for CI.                                                                                   |
