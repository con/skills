# Troubleshooting

| Symptom                                                                      | Cause and fix                                                                                                                                                                                               |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Captures from several Playwright projects overwrite each other               | Chromatic names an archive by the test's file, describe and title, never its project; only viewport differences survive the upload. Set viewports per test with `forEachViewport`; keep one Chromium project. |
| Two captures overwrite each other within one project                         | Same archive name: titles that differ only in case or punctuation collide (Chromatic lowercases the whole title path and collapses punctuation), which Playwright's exact duplicate-title check lets through; so do two `takeSnapshot` calls with one name in a test. Rename one title. |
| A page's snapshot shows the index page                                       | The URL did not match a built entry and Vite's default `appType: "spa"` fell back to `index.html`. For HTML entries, set `appType: "mpa"` so a miss 404s (a routed app keeps `spa`: a history router needs `index.html` for every route, see `several-pages.md`), and check the page is in `configs/pages.ts` and its URL form against the table in `several-pages.md`. |
| `Chromatic archives directory cannot be found`                               | A custom `outputDir` in the Playwright config, or the tests did not run. Leave `outputDir` alone, or set `CHROMATIC_ARCHIVE_LOCATION` to that `outputDir` as a path from the working directory (the archive bins append `chromatic-archives` themselves; the fixture writes there regardless). |
| `build-archive-storybook` ignores `--output-dir`                             | It was run through `npm exec`, which eats the flag. Call `./node_modules/.bin/build-archive-storybook` directly.                                                                                            |
| `Failed to run chromatic --playwright`                                       | No Chromium project; Chromatic archives only from Chromium.                                                                                                                                                 |
| Every story re-snapshotted after a version bump                              | The version stamp is not pinned under `CHROMATIC_STATIC_VERSION` in the Vite config Storybook loads (or in `viteFinal`, when it loads none).                                                                |
| Text pixels moved with no code change                                        | The runner image changed (compare the printed `ImageVersion`), or the branch is behind `main`. Accept, or merge `main` and re-read.                                                                         |
| Workflow fails on a Dependabot branch or in a contributor's fork, or a fork's pull request shows no Chromatic check | No secrets there. The `dependabot[bot]` guard skips the former; a fork's `on: push` run happens in the fork, and nothing runs in this repository for its pull request, so it needs the split in `fork-pull-requests.md`. |
| `ERR_REQUIRE_ESM` or Node version errors from `@chromatic-com/playwright`    | The package is ESM-only and needs Node 22; raise `node-version` in the workflow.                                                                                                                             |
| Stories show the wrong theme on CI, or only one theme reaches Chromatic      | Nothing pins the theme, or `parameters.chromatic.modes` is missing from `preview.ts`, or the decorator does not read `context.globals.theme`. Add the decorator and the modes block from the template.      |
| A raw-HTML page story shows broken images                                    | The markup's asset URLs bypass Vite. Mount `src/assets` in `main.ts` with `to` set to the URL the markup resolves to in Storybook's iframe (`/src/assets`, or `/assets` under `root: "src"`); a page-local URL in a nested page (`./img/x.png`) needs its own `staticDirs` entry at the hoisted path (`/img`), see `several-pages.md`. |
| A page story renders unstyled                                                | The page links a stylesheet of its own that `preview.ts` does not import; import it at the top of that page's story file.                                                                                   |
| A page works under `npm run dev` but 404s under `vite preview` and in production | The dev server serves any HTML file; the build contains only the entries in `build.rollupOptions.input`. Add the page to `configs/pages.ts`, which the Vite config reads.                                 |
| `playwright install --with-deps` fails locally asking for a password          | `--with-deps` installs system libraries and needs root. Locally run `npx playwright install chromium`; the flag is for CI.                                                                                   |
